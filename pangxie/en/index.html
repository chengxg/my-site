3D Printer Little Crab Eddy-Current XY Offset Calibration

The first original open-source Klipper eddy-current tool calibration module for 3D printers — extremely high repeatability, fast calibration, and a clever calibration approach.

3D Printed Eddy-Current Leveling Coil — Little Crab Bed Scanning Coil

A 3D-printed eddy-current leveling coil with native Klipper driver support — similar to the IDM scanning coil, communicating over I2C.

3D Printed Eddy-Current Leveling Coil — Beginner Tutorial

A beginner-friendly tutorial for the 3D-printed eddy-current leveling coil — how to modify the configuration files.

Pressure Leveling Sensor

A DIY pressure leveling sensor for 3D printers — one of the few reliable nozzle-limit sensor solutions, with high-speed strain-gauge sampling, data visualization, and op-amp, CS1237, and LDC1612 eddy-current variants.

3D Printer CAN Toolhead — STM32F446 Little Crab Full-Spec Toolhead

The first toolhead built on the STM32F446 — the Little Crab toolhead, packed with XH2.54 terminals, switchable USB/serial/CAN communication, an integrated LDC1612 for eddy-current bed scanning, and a MAX31865 chip.

3D Printer Mainboard — STM32 High-Performance Mini 8-Axis Little Crab Mainboard (4-Layer)

An upgraded version of the "STM32 high-performance mini 8-axis mainboard" project, renamed "Little Crab mainboard". Core and base boards are 4-layer, the core board has extra terminals, and every IO is protected — currently the only one of its kind.

3D Printer Mainboard — STM32 High-Performance Mini 8-Axis Mainboard (2-Layer)

An STM32F446/STM32H750 high-performance mini 8-axis mainboard in a 2-layer design, with over-voltage protection that survives direct 24V input, using a serial-communication toolhead.
