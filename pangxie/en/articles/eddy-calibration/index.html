3D Printer Little Crab Eddy-Current XY Offset Calibration

Author: 仁泉之子

1. The Little Crab eddy-current XY offset calibration — two months of original self-developed work. DIY printers now have eddy-current XY calibration too — currently the only one of its kind.

2. Automatically calibrates the XY center position of a 3D printer's tools (hotends/nozzles) using an LDC1612 eddy-current sensor. Mainly intended for multi-hotend or multi-toolhead printers, solving the XY offset problem between different toolheads.

3. Fast probing, easy to use, extremely high repeatability: with the hotend unchanged, probing repeatability is under 0.005 mm, and fixed-offset accuracy is under 0.02 mm.

4.Working principle:as the nozzle sweeps across the coil's center point, the frequency traces a parabola, reaching an extremum exactly at the center. Near the center, the frequency waveform is parabolic — just find the vertex of the parabola to locate the center. As long as the nozzle sweeps past the center area from at least two directions, the exact center of the coil can be determined.

5. This coil currently only measures XY offset calibration. Z calibration requires a nozzle-Z-limiting probe such as a pressure bed or eddy scanning-bed tap. Pay attention to the nozzle scanning height — it should sweep about 0.5 mm above the coil.

6. This feature is a Klipper plugin that reuses Klipper's eddy driver ldc1612.py; it requires the latest Klipper version. See my eddy bed-scanning project for details: 3D Printed Eddy-Current Leveling Coil — Little Crab Bed Scanning Coil  You can also simply flip the eddy bed-scanning coil over and use it for XY offset calibration.

7. Note that I2C communication consumes resources — you need a high-clock MCU; the STM32F072 won't do. If you must use one, you'll need to edit ldc1612.py to lower the sampling rate; see the bed-scanning tutorial. This module is fixed to the heated bed and needs wiring to the mainboard.

8. Eddy-current XY calibration GitHub repo: https://github.com/chengxg/tool_eddy_calibration   

   The tutorial is also at: https://demo.chengxg.top/pangxie/#/articles/eddy_calibration

   Hotend-swapping project: https://github.com/cx330-TXY/Simple-Multi-Hotend

9. Little Crab QQ group: 1057494383; hotend-swapping QQ group: 757271588.

 
Installing the plugin
Download the plugin file and upload it to the Klipper extras directory  /klipper/klippy/extras/tool_eddy_calibration.py, then restart the Klipper service.

Add the sensor configuration block

travel_speed_z: 10.0        # Z travel speed
save_data: True             # whether to save probe data to a CSV file

1. TEST_LDC1612 — sensor test command

Quickly checks whether the LDC1612 sensor is working, collecting frequency data over a short period and printing statistics. Use this after soldering to verify it works.

The sensor coil's resonant frequency is currently around 2.2 MHz.

2. TOOL_EDDY_CALIBRATE — calibrate the tool center

Runs the full tool XY center-position calibration — the core command. When it finishes, the result is stored in the plugin'slast_result variable.

In G-code you can read it like this: {% set res = printer["tool_eddy_calibration calibrator_xy"]['0'] %}  X coordinate res.x, Y coordinate res.y, Z coordinate res.z

 
Parameter Required Default Description
TOOL Yes - Tool identifier, e.g. 0, 1
DIR No 45,135 Scan direction angles (comma-separated), 0°=X+, 90°=Y+, at least two directions
PRE_DIR No Same as DIR

Pre-scan direction angles (used on first calibration)

Used to refine the manually configured coil center (coil_x, coil_y)
REPEATS No 1

Number of repeat measurements (1-10); averaging multiple runs improves precision

A single pass is already quite accurate — usually one is enough
PAIR_CANCEL No 0

Pair-cancel motion hysteresis (0=off, 1=on)

Usually not needed: belts have motion hysteresis, so the center found from the reverse direction differs by about 0.03 mm
SCAN_HEIGHT_OFFSET No 0.0

Fine Z offset adjustment (+ away from coil, - toward coil)

For hotends with large height differences, to avoid crashing due to the height gap
CENTER_XY No -

Overrides the initial scan center point, format X,Y   

If not set, (coil_x, coil_y) from the config is used

Generally used when different hotends' XY offsets are so large that the center point is badly displaced
 

Command usage examples:

; Basic calibration (default 45° and 135° directions) TOOL_EDDY_CALIBRATE TOOL=0

; Automatic reverse-direction scanning with pair-cancel of motion hysteresis  TOOL_EDDY_CALIBRATE TOOL=0 DIR=0,90 PAIR_CANCEL=1

; 3 repeat measurements + fine-tuned scan height  TOOL_EDDY_CALIBRATE TOOL=1 DIR=45,135 REPEATS=3 SCAN_HEIGHT_OFFSET=0.2

; Specify pre-scan directions TOOL_EDDY_CALIBRATE TOOL=0 PRE_DIR=0,90 DIR=45,135

; Specify the initial scan center point TOOL_EDDY_CALIBRATE TOOL=0 CENTER_XY=33.0,11.0 DIR=0,90

 

Command execution flow:

1. Check that the printer is homed

2. Determine the scan center: use the existing center point first → then the CENTER_XY parameter override → finally the configured coil_x/coil_y

3. If no exact center is known yet, pre-scan along the PRE_DIR directions to refine the manually specified approximate coil center. The scan result is cached and skipped on subsequent runs

4. Scan along each direction given by DIR, collecting frequency data

5. Detect the frequency peak position for each direction

6. Reconstruct the center coordinates via LSQ or the pair-averaging method

7. If REPEATS > 1, repeat steps 4-6 and average

8. Finally, move to directly above the detected center point

 

This printed center-point position can be written back into the coil's coil_x,coil_y coordinates in the configuration.

 

3. GET_TOOL_CENTER — query calibration results

Queries the last calibration result for the given tool.

 

4. SET_TOOL_Z — set the tool Z coordinate

This module currently does not support Z calibration. Sets the tool's Z coordinate value, typically from an external probe's measurement — the Z position obtained via a pressure bed or eddy tap.

5. CLEAR_TOOL_CENTER — clear the scan center point

Used to clear the pre-scanned center point from the TOOL_EDDY_CALIBRATE command. After clearing, runningTOOL_EDDY_CALIBRATE again will first do a pre-scan to find the center point, then do the precise scan.

6. LDC_CALIBRATE_DRIVE_CURRENT CHIP=calibrator_xy — coil drive-current calibration command

This command is the same as Klipper's eddy bed-scanning one; see my Little Crab eddy bed-scanning project for usage.

    G1 X{vars.safe_x} Y{vars.safe_y} Z{vars.safe_z} F9000

    # Get the Z offset using a nozzle-limiting probe
    PROBE METHOD=tap SAMPLES=3
    G1 X{vars.safe_x} Y{vars.safe_y} Z{vars.safe_z} F9000
    DO_CALIBRATE_TOOL TOOL={tool}
    _DO_SAVE_CALIB_RESULT TOOL={tool}

    G90


[gcode_macro DO_CALIBRATE_TOOL]
gcode:
    {% set tool = params.TOOL|default(0)|int %}
    {% set probeZ = printer.probe.last_probe_position.z %}
    # Clear the previous center point
    CLEAR_TOOL_CENTER TOOL={tool}
    # Set the Z position probed by the nozzle-limiting probe
    SET_TOOL_Z TOOL={tool} Z={probeZ}
    {% set tool0ProbeZ = 0.0 %}
    {% if '0' in printer["tool_eddy_calibration calibrator_xy"] %}
      {% set tool0ProbeZ = printer["tool_eddy_calibration calibrator_xy"]["0"].z %}
    {% endif %}
    # Perform XY offset calibration, applying a Z offset relative to tool0 to avoid the nozzle hitting the coil
    TOOL_EDDY_CALIBRATE TOOL={tool} DIR=0,90 PAIR_CANCEL=0 SCAN_HEIGHT_OFFSET={probeZ-tool0ProbeZ}

    {% set res0 = printer["tool_eddy_calibration calibrator_xy"]["0"] %}
    {% set res = printer["tool_eddy_calibration calibrator_xy"][tool|string] %}
   
    {% if tool == 0 %}
        # T0 always stores 0
        SAVE_VARIABLE VARIABLE=t0_offset_x VALUE=0.0
        SAVE_VARIABLE VARIABLE=t0_offset_y VALUE=0.0
        SAVE_VARIABLE VARIABLE=t0_offset_z VALUE=0.0
        {action_respond_info("✅ T0 reference point coordinates locked")}
    {% else %}
        # Other tools store the probed result
        SAVE_VARIABLE VARIABLE=t{tool}_offset_x VALUE={(res.x-res0.x)|round(4)}
        SAVE_VARIABLE VARIABLE=t{tool}_offset_y VALUE={(res.y-res0.y)|round(4)}
        SAVE_VARIABLE VARIABLE=t{tool}_offset_z VALUE={(res.z-res0.z)|round(4)}
        {action_respond_info("✅ T" ~ tool ~ " offsets saved automatically")}
    {% endif %}


# ---------------------------------------------------------
# Batch-calibrate all tools
# ---------------------------------------------------------
[gcode_macro CALIBRATE_ALL_TOOLS]
gcode:
    {% set vars = printer["gcode_macro _TOOL_CALIB_VARS"] %}
    {action_respond_info("Starting fully automatic tool calibration...")}
    # Pre-heat everything to 150C — mind your power supply capacity
    {% for t in range(0, vars.tool_count) %}
        M104 S150 T{t}
    {% endfor %}
    # Iterate over all tools (range(0, N) yields 0 to N-1)
    {% for t in range(0, vars.tool_count) %}
        CALIBRATE_TOOL TOOL={t}
    {% endfor %}
    # Turn heaters off
    {% for t in range(0, vars.tool_count) %}
        M104 S0 T{t}
    {% endfor %}
    untool
    {action_respond_info("All tools calibrated")}

 

III. Scanning algorithm overview

1. Scanning process

The scan in each direction is a straight-line move of length L at angle θ about the center point:

  • Start: (center_x - L/2 · cosθ, center_y - L/2 · sinθ)
  • End: (center_x + L/2 · cosθ, center_y + L/2 · sinθ)

During the scan, frequency data is sampled at a fixed rate (LDC1612 default 400 sps) while print time is recorded, so frequency can be mapped to position.

2. Peak detection

Peak detection has three steps:

  1. Coarse location: excluding the outer 15% of the data, search for the frequency extremum in the middle region
  2. Automatic type detection (auto mode): compare the mean frequency of the central 30% region against the outer 15% regions to determine whether the waveform is peak-shaped (large coil) or valley-shaped (small coil)
  3. Fine location: near the extremum, a weighted least-squares parabola fit (Gaussian weights) achieves sub-sample positioning accuracy

Parabola fitting formula: y = a·x² + b·x + c, with the extremum at x = -b/(2a). The weights follow a Gaussian distribution — the closer to the peak, the larger the weight — suppressing the influence of noisy points far from the peak.

3. Center reconstruction algorithm

Two reconstruction methods are available depending on the PAIR_CANCEL parameter:

LSQ method (PAIR_CANCEL=0)

Directly solves for the center coordinates by least squares over the projections of each direction's peak. Suited to asymmetric scan directions or a small number of directions.

Pair-averaging method (PAIR_CANCEL=1)

Averages the projections of the θ and θ+180° directions, canceling the motion system's directional hysteresis (different accuracy forward vs. backward), then solves with LSQ.

For example, DIR=0,90 with PAIR_CANCEL=1 automatically expands into the four directions 0,90,180,270, forming two pairs of opposite symmetric scans.

 

IV. Probing accuracy and nozzle eccentricity

The eddy-current sensor detects the nozzle's center of mass. If the nozzle's center of mass is eccentric relative to the orifice center, you can add a fixed offset when loading the offset values.

Currently all offsets are computed relative to the first nozzle. If the first nozzle itself is eccentric, the error of every subsequent nozzle includes not only its own eccentricity but also the first nozzle's eccentricity stacked on top.

To eliminate this fixed error further, we can make a fake nozzle to serve as the reference — a conical locating pin that is solid inside, so there is no eccentricity.

This removes the reference nozzle's eccentricity problem, and in theory halves the fixed offset error.

 

This page tool is provided: import the CSV saved by the plugin and you can see the frequency waveform as the coil is swept — the frequency is lowest at the center point.

Single-hotend repeat-measurement positioning accuracy is very high — repeatability is basically under 0.01 mm.

------------------2026-07-23 update  dual-coil board added------------------

This is the recently mass-produced board. In the future the large coil may be used for eddy-current PA calibration — it can detect nozzle deflection under force. The large coil can also be used for XY offset calibration, but it effectively senses the heater block rather than the nozzle, so it is less accurate than the small coil. Currently the Klipper firmware only supports the coil on channel 0; channel 1 is not usable yet. I will modify the code later to add support for the channel-1 coil. Channel 0 is wired to the small coil and channel 1 to the large coil.

The hole in the middle of the large coil lets the nozzle purge material into it; by detecting nozzle deflection during extruder acceleration and deceleration, the pressure inside the nozzle can be inferred, and from that the material's PA value can be determined. This is still just an idea — research hasn't started yet.
