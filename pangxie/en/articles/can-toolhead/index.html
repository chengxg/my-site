3D Printer CAN Toolhead — STM32F446 Little Crab Full-Spec Toolhead

Author: 仁泉之子

This 3D printer toolhead is for the Klipper firmware — the STM32F446 Little Crab full-spec toolhead. It uses the STM32F446RCT6 as the MCU: abundant resources, strong performance, and switchable USB/serial/CAN communication — use whichever you like. All terminal blocks are XH2.54 — large and easy to wire.

 

1. 3 endstop ports — two with 5V supply, one with switchable 5V/24V supply. STOP2 has diode isolation and accepts high-voltage input, so other three-wire devices can be connected.

2. 2 thermistor terminals — one for the hotend, the other usable for the scanning coil's temperature compensation; 1 onboard thermistor measures chamber temperature.

3. 3 controlled fans, 1 heated-bed-class high-power heater cartridge output.

4. 1 4-pin I2C terminal breakout, 1 4-pin expansion terminal, 5V power output.

5. 1 4-pin CAN terminal breakout — flash an ordinary CAN firmware, or a UTOC firmware if you prefer.

6. Integrated TMC2226 stepper driver — good heat dissipation, easy to solder.

7. Integrated LDC1612 chip with direct bed-scanning support; use the companion coil (very compact) or an IDM coil.

8. Integrated MAX31865 chip supporting PT100/PT1000 temperature sensors, 2-wire and 3-wire.

9. Integrated ADXL345 accelerometer.

10. SPI pads broken out — 5 spare IOs total, highly expandable.

 

At one point the TJA1051T/3 CAN chips I bought were not great: hot-plugging the toolhead left the MCU in a bad state, unable to enter DFU for flashing. The circuit has since been redesigned so that even a counterfeit CAN chip cannot affect the MCU. Pin 8 of the CAN chip supports both the REF function (e.g. TJA1050T) and chips whose pin 5 is VIO (e.g. TJA1051T/3, SIT1051T/3). If you use a 1050-series chip, do not solder the diode next to it.

You can flash USB firmware, CAN firmware, or serial firmware, plus a UTOC firmware. When talking to the host or mainboard, both ends must use the same interface.

Once the top side is fully soldered, you can already flash firmware over USB-to-serial.

Most terminals have no protection — double-check your wiring before connecting. In particular, mechanical endstop switches: connect only IO and GND, never all three wires!

Post-soldering verification:

 

After soldering, do not solder the through-hole terminals yet — flash the firmware first via USB-to-serial.

Of course, you can also finish soldering both sides and then flash via USB.

If STM32CubeProgrammer keeps failing to connect, the MCU soldering has a problem.

Just power the board from 5V for verification — none of these chip checks need 24V.

1. ADXL345 / LIS2DW chips

Simply run the ACCELEROMETER_QUERY command; the console should print accelerometer data like // accelerometer values (x, y, z): 9400.615463, 74.020594, -766.095498

2. MAX31865 chip

Prepare a PT100 sensor, add the PT100 configuration, and check that a temperature shows up. If something is wrong, Klipper will raise an error.

3. LDC1612 chip

Connect the coil and run LDC_CALIBRATE_DRIVE_CURRENT chip=eddy_probe; it should return: // probe_eddy_current eddy_probe: reg_drive_current: 19

4. TMC2226 chip

In the [extruder] configuration, set the minimum extrusion temperature to min_temp: -200. Without the extruder motor connected and without 24V power, click "Extrude" on the web UI — no error means it passes.

5. Hotend heater MOS

Simply command a temperature; the heating indicator LED lighting up is enough.

6. WS2812B LED

Add the relevant configuration and set a color on the web UI — as long as it lights up, it works.

-------------------------------- 2026-03-23 minor update ---------------------------------------------------------

The onboard LDC1612 chip is removed and replaced by a standalone eddy-current coil for more stable performance. The freed coil terminal is now broken out as two IOs, PC0 and PC1, increasing the IO count. All broken-out terminal IOs have a 220-ohm series resistor for protection.

 

-------------------------------- 2026-04-20 minor update ---------------------------------------------------------

Still no LDC1612 — replaced by a standalone eddy-current coil for more stable performance.

ADXL345 accelerometer prices have gotten too high lately — higher than the MCU itself — so it is replaced by the LIS2DW with adjusted pins. The SN74LV1T34DBVR-TP MOS driver chip has also gotten much more expensive; other drop-in substitutes work fine.

The LIS2DW pins have been adjusted:

LIS_CS=PC8,LIS_MOSI=PC6,LIS_MISO=PC7,LIS_SCK=PC9, LIS_INT1=PC3, # LIS2DW version, software SPI
