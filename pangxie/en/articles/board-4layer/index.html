3D Printer Mainboard — STM32 High-Performance Mini 8-Axis Little Crab Mainboard (4-Layer)

Author: 仁泉之子

This is an upgraded version of the 2-layer board 3D Printer Mainboard — STM32 High-Performance Mini 8-Axis Mainboard

Officially named: Little Crab Mainboard

Both the core board and the base board are 4-layer boards

For the project origin and circuit changes, see the old project description

 

Core board:

GPIO protection on the core board is upgraded: apart from the CAN and USB terminals, all other pins now have GPIO protection, and IO over-voltage triggers automatic shutdown on the base board

The core board still uses the STM32H750VBT6; the USB-to-serial chip is replaced with a CH343P, and the CAN transceiver with a TJA1051T/3

The core board stacks two rows of through-hole terminals: solder the rear terminals first, trim their pins flush, then solder the front ones

The core board's USB/CAN/serial ports can be mated without adjusting the pin order  3D Printer CAN Toolhead — STM32F446 Little Crab Full-Spec Toolhead

1. 2× 3-pin terminals, usable for endstops, with 5V power output

2.  4× 2-pin thermistor terminals, also usable for endstops

3.  4× 4-pin terminals, 1× CH343P UART interface, 1× USB interface, 1× CAN interface, 1× I2C interface

4. 1× USB Type-A receptacle

 

Base board:

Base board layout optimized: the driver jumper selectors are removed and replaced by solder-jumpers on the back to select UART/SPI/standalone mode; step1 and step2 now have independent EN

If you use an old-version core board, you need to run a fly-wire to enable step1's EN

The STC32G8K64 5V control pin arrangement on the base board changed, avoiding a brief flicker of the 5V rail at power-on

All 35V capacitors on the base board are replaced with through-hole capacitors — easier to solder and higher capacitance

 

1.  6× endstop terminals, STOP1 and STOP2 have switchable 12V/24V power output with diode-isolated IO and accept high-voltage input, STOP3/STOP4 are 2-pin endstop terminals shared with the sensorless homing of the STEP1/STEP2 drivers, STOP5/STOP6 are 3-pin endstop terminals with 5V power output

2. 4× controlled fan terminals, FAN1/FAN2 with switchable 5V/12V/24V supply, FAN3/FAN4 fixed 24V supply

3. 8× stepper motor drivers, the first 6 support UART/SPI/standalone mode, the last two support UART mode only

4. 2× high-power heater cartridge outputs, requiring a separate power supply and soldered lead-out wires

5. The power-monitor host UI page address is unchanged, online at: https://demo.chengxg.top/mini8/

aliases:
    # step1-step6 support SPI, spi_bus: spi2
    DIR1=PD3, STEP1=PD4, UART1=PD2, EN1=PD6,   # step1  
    DIR2=PC8, STEP2=PC12, UART2=PD0, , EN2=PD1,          # step2
    DIR3=PC9, STEP3=PD8, UART3=PD14, EN3=PB1,  # step3
    DIR4=PC6, STEP4=PD13, UART4=PD12,          # step4 EN shared with step3
    DIR5=PE14, STEP5=PD15, UART5=PD9, EN5=PB2, # step5
    DIR6=PC5, STEP6=PB12, UART6=PB0,           # step6 EN shared with step5
    DIR7=PA5, STEP7=PA6, UART7=PA7, EN7=PC4,   # step7
    DIR8=PA2, STEP8=PA3, UART8=PA1, EN8=PA0,   # step8
    FAN1=PA8, FAN2=PC7, FAN3=PA10, FAN4=PA9,   # FAN1, FAN2 support 5V/12V/24V switching
    STOP1=PA4, STOP2=PE12,            # endstop 3-pin STOP1/STOP2 accept high-voltage input with diode isolation, support 12V and 24V power output
    STOP3=PE13, STOP4=PE11,           # endstop 2-pin step1/step2 sensorless homing
    STOP5=PE10, STOP6=PE9,            # endstop 3-pin 5V power output
    STOP7=PB7, STOP8=PB6,             # on the core board, endstop 5V power output
    T1=PC0, T2=PC3, T3=PC1, T4=PC2,   # on the core board, thermistors
    H1=PD11, H2=PD10,                 # heaters, H1 high-power
    LED=PB4,                          # Klipper run indicator !PB4
    SDA=PB11, SCL=PB10,               # on the core board, I2C interface i2c_bus:i2c2
    SHUT=PD7                          # high level = automatic shutdown
